# Prospero Themes artwork and typography

`source/blue-hour.png` is the original artwork generated with the built-in Imagegen tool on 2026-10-13. Prompt: cinematic midnight ocean, a luminous icy-blue crescent planet above a mountainous horizon, quiet dark left third for text, restrained cool blues, realistic water, no text, logos or interface.

`blue-hour.bmp` and `blue-hour-preview.png` are resized runtime copies. `tools/bake-assets.py` reproduces these copies and the six raster font atlases (`inter-28-semibold.p5font` is the weight-600 face of the 28 px size).

Inter is from https://github.com/google/fonts/tree/main/ofl/inter. The font is distributed under the SIL Open Font License retained in `fonts/OFL.txt`. The source font is kept in `source/Inter.ttf`; only its raster atlases and licence ship in the app.
